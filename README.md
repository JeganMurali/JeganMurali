### 🧠 About Me

I'm a software builder from **Pallippatti, Tamil Nadu, India**, working across AI, data science, and full-stack development. I like turning ideas into working products — from ML-powered health tools to data pipelines and web apps.

- 🔭 **Currently building:** [AURA](https://github.com/JeganMurali/AURA-) — an AI-powered mental health companion, and [Neuro-CRISPR-KAN](https://github.com/JeganMurali/Neuro-CRISPR-KAN), exploring Kolmogorov-Arnold networks for bioinformatics
- 🌱 **Learning:** advanced ML architectures and scalable backend systems
- 💬 **Ask me about:** Python, data science, applied ML, and shipping side projects fast
- 📍 **Based in:** Pallippatti, Tamil Nadu, India
